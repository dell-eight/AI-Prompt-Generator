# SEO and Launch Marketing

This plan uses assumed search intent for an MVP launch. It does not include
fake keyword volume, fake testimonials, or paid-feature claims.

## Product Tagline

PromptForge helps you browse, save, copy, and generate better AI prompts.

## Short Description

PromptForge is an AI prompt library and generator for people who want clearer
results from ChatGPT, Cursor, Claude, Canva AI, image generators, writing tools,
coding assistants, debugging workflows, business planning, and automation tools.

## One-Sentence Pitch

Turn vague AI requests into structured prompts with context, goals, constraints,
output formats, and quality checks.

## Homepage Message

- Headline: PromptForge
- Subheadline: AI prompt library and generator for clearer, stronger prompts.
- Primary CTA: Browse prompt library
- Secondary CTA: Generate a prompt

## Social Launch Posts

### Short Post

I built PromptForge, an AI prompt library and generator for better ChatGPT,
Cursor, Claude, Canva AI, writing, coding, debugging, business, and automation
prompts. Browse templates, save useful prompts, or generate a structured prompt
from your own goal.

### Builder Post

Most weak AI results start with vague prompts. PromptForge helps users add the
missing pieces: role, goal, context, constraints, output format, and quality
checks. The MVP includes a searchable prompt library, saved prompts, admin CRUD,
and a server-side prompt generator.

### Product Hunt-Style Description

PromptForge is a searchable AI prompt library and generator. Browse prompt
templates by tool, category, difficulty, and tag, save prompts to your account,
and generate copy-paste-ready prompts for common AI workflows.

## Category Page Strategy

The current `/prompts` page supports query URLs that can be used in launch
content, such as:

- `/prompts?tool=ChatGPT`
- `/prompts?category=coding`
- `/prompts?category=debugging`
- `/prompts?category=book-writing`
- `/prompts?category=business-ideas`
- `/prompts?category=ai-automation`

Future dedicated SEO landing pages can be added for top categories once search
demand and analytics show which use cases matter most.
